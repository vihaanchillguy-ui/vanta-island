# Vanta Island

A browser-based macOS-inspired Dynamic Island preview.

## Run it
Open `index.html` in a browser, or enable GitHub Pages:
1. Open the repository Settings.
2. Select **Pages** in the sidebar.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select `main` and `/ (root)`, then Save.

The preview includes an expandable floating island, demo music controls, animated gradient wallpapers, clock, battery API detection where supported, and local settings. It is a web preview, not yet a native macOS overlay or a downloadable DMG.
